---
description: Generar archivos para hosting (Build)
---

Este workflow prepara tu sitio para ser subido a internet.

1. Instalar dependencias necesarias
// turbo
2. npm install

3. Generar la carpeta de producción (dist)
// turbo
4. npm run build

5. ¡Listo! Ahora puedes tomar el contenido de la carpeta `dist` y subirlo a tu hosting. Consulta `GUIA_DESPLIEGUE.md` para más información.
